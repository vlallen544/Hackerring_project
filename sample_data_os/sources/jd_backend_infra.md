# Job Description: Backend Engineer – Cloud Infrastructure, Hyderabad (Campus Hiring 2026)

## Responsibilities
Build and operate backend services that run in containers on Linux servers.
Debug performance problems in production systems.

## Required skills
Strong understanding of processes, threads and concurrency, including locks and deadlock avoidance.
Knowledge of virtual memory and how paging affects application performance.
Hands-on experience with Linux containers, including namespaces and cgroups.
Familiarity with how the Linux CPU scheduler shares CPU time between services.

## Good to have
Experience with Docker and Kubernetes, and a programming language such as Go or Python.
