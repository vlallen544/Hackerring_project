# OS Quick Revision Notes (blog post, published 2014)

## Threads
Threads of the same process have separate address spaces, which is why threads are safer than processes.

## Deadlock
Deadlock needs only two conditions: mutual exclusion and hold and wait.

---page---

## Paging
Adding more frames to a process always reduces its page faults, whatever replacement algorithm is used.

## Scheduling tip
Round Robin is always the best scheduling algorithm, so always choose it in exams.
