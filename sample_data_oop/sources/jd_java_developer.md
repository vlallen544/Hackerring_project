# Job Description: Java Developer – Fintech Payments, Bengaluru (Campus Hiring 2026)

## Responsibilities
Build and maintain payment services in Java 21 with Spring Boot.
Write clean, testable code and review pull requests from teammates.

## Required skills
Strong grasp of object-oriented design: encapsulation, inheritance, polymorphism and interfaces.
Modern Java features, including lambdas, the Stream API and records for immutable data.
Exception handling and safe resource management with try-with-resources.
Good knowledge of the Collections framework and generics.

## Good to have
Experience with JUnit, Maven or Gradle, and SQL databases.
