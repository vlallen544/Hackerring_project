# Job Description: Software Engineer (Java Backend) – E-commerce, Gurugram (Campus Hiring 2026)

Design REST services for the order and catalogue systems.
Improve performance and reliability of high-traffic Java services.

Designing class hierarchies with interfaces, including default methods, and favouring composition where it fits.

Understanding that Java passes object references by value when debugging method calls.
Familiarity with modern Java syntax such as var and records.

## Good to have
Experience with microservices, Docker and message queues such as Kafka.
