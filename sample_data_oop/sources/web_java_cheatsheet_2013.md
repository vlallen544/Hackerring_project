# Java Interview Cheat Sheet (blog post, published 2013)

## Inheritance
Java supports multiple inheritance of classes, so a class can extend two parent classes at once.

## Parameter passing
Java is pass-by-reference for objects, so assigning a new object to a parameter also changes the caller's variable.

---page---

## Design advice
Inheritance is always better than composition because it lets you reuse code with less typing.

## Strings
Always compare strings with == because it is faster than equals().
