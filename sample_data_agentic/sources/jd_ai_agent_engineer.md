# Job Description: AI Agent Engineer – Payments Platform, Bengaluru (Campus Hiring 2026)

## Responsibilities
Build LLM agents that help operations teams investigate failed payments and customer disputes.
Connect agents to internal systems safely and keep a human in the loop for every refund.

## Required skills
Hands-on experience with native tool calling (function calling) and structured JSON outputs.
Experience building or using MCP (Model Context Protocol) servers to connect agents to tools and data.
Building retrieval-augmented generation (RAG) pipelines over internal documents.
Defending agents against prompt injection, with human approval for irreversible actions.

## Good to have
Python, and experience tracing and evaluating agent runs.
