# Job Description: Applied AI Engineer – LLM Platform Team, Pune (Campus Hiring 2026)

## Responsibilities
Run the shared platform that every product team uses to ship LLM features and agents.
Keep quality, cost and latency under control as usage grows.

## Required skills
Context engineering: choosing what goes into the model's context window at each step.
Designing multi-agent workflows with an orchestrator and specialised worker agents.
Building evaluation sets and running evals after every prompt or model change.
Observability: tracing every model and tool call of an agent run.

## Good to have
Experience reducing cost with prompt caching and routing simple requests to smaller models.
