# Job Description: Junior Data Analyst – E-commerce Company (Campus Placement Drive)

## What you will do
Analyse orders, returns and customer behaviour using SQL.
Rank top-selling products by category and track month-over-month growth.

## Must-have skills
SQL: joins, subqueries, CTEs and window functions (RANK, DENSE_RANK, LAG).
Data integrity: understanding of primary keys, foreign keys and constraints.
Ability to explain the difference between WHERE and HAVING clearly.

## Nice to have
Query optimization using indexes.
Excel or Google Sheets for quick analysis.
