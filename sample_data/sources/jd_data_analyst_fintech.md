# Job Description: Data Analyst – Fintech Startup, Bengaluru (Campus Hiring 2026)

## Responsibilities
Write SQL queries to analyse transaction and customer data.
Build dashboards that track daily, weekly and monthly business metrics.

## Required SQL skills
Strong command of joins across multiple tables, including LEFT JOIN and self join.
Window functions such as ROW_NUMBER, RANK, LAG and running totals are used daily for cohort and trend analysis.
Common Table Expressions (CTEs) for writing readable multi-step queries.
GROUP BY and HAVING for aggregated reporting.

## Good to have
Understanding of indexes and reading EXPLAIN output to speed up slow queries.
Basic Python (pandas) and a BI tool such as Power BI or Tableau.

## Interview process
Online SQL test, followed by a live case-study round on real business data.
