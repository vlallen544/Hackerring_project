# Job Description: Software Engineer – AI-Native Product Team, Hyderabad (Campus Hiring 2026)

## Responsibilities
Build product features with coding agents as everyday tools, from specification to release.
Own the quality of every change you merge, whether you or an agent wrote it.

## Required skills
Working with coding agents that edit multiple files and run tests, guided by a written spec and plan.
Careful review of AI-generated diffs, including edge cases and outdated library APIs.
Writing and maintaining automated tests that run in continuous integration.
Security awareness: protecting secrets and checking that suggested packages are genuine.

## Good to have
TypeScript or Python, and keeping a project instruction file for coding agents up to date.
