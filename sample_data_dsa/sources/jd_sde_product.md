# Job Description: Software Engineer (New Grad) – Product Company, Bengaluru (Campus Hiring 2026)

## Responsibilities
Design, build and test backend features used by millions of users.
Review code and improve the performance of existing services.

## Required skills
Strong problem solving with arrays, strings, hashing and trees.
Graph algorithms including BFS, DFS and shortest paths.
Dynamic programming for optimisation problems.
Sliding window and two pointers techniques for efficient array and string processing.
Ability to analyse time and space complexity using Big-O notation.

## Good to have
Experience in Python, Java or C++ and familiarity with Git.

## Interview process
Online coding test, two data structures and algorithms rounds, and a system design discussion.
