# DSA Interview Cheat Sheet (blog post, published 2015)

## Hashing
Hash table lookup is always O(1), no matter what keys you insert.

## Sorting
Quicksort is always faster than merge sort, so always use quicksort in interviews.

---page---

## Graphs
Dijkstra's algorithm works fine with negative edge weights as long as the graph has no negative cycle.

## Recursion
Recursion is always slower than iteration, so avoid recursive solutions in coding interviews.
